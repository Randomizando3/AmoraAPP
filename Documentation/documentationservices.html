Documentação de Services

AmoraApp • Camada de regras de negócio e integração

Auth

FirebaseAuthService

Responsável pela autenticação do usuário via Firebase.

  • Login e logout
  • Criação de conta
  • Usuário autenticado atual
  • Recuperação de token (IdToken)
Database

FirebaseDatabaseService

Camada de acesso ao Firebase Realtime Database.

  • Leitura e gravação de perfis
  • Atualização parcial de dados
  • Busca de informações públicas de usuários
Storage

FirebaseStorageService

Gerencia upload e exclusão de arquivos no Firebase Storage.

  • Upload de fotos
  • Upload de vídeos
  • Geração de URLs públicas
  • Remoção de arquivos
Discover

MatchService

Controla curtidas, dislikes, matches e discover.

  • Like e dislike de perfis
  • Detecção automática de match
  • Lista de matches
  • Lista de usuários que curtiram o perfil
  • Perfis exibidos no Discover
Friends

FriendService

Gerencia amizade entre usuários.

  • Solicitação de amizade
  • Aceite ou recusa
  • Lista de amigos
  • Remoção de amizade
Chat

ChatService

Camada principal de gerenciamento de chats.

  • Criação de chats privados
  • Envio de mensagens
  • Listagem de mensagens
  • Resumo de conversas
Chat

MessageService

Wrapper simples sobre o ChatService.

  • Compatibilidade com código legado
  • Envio de mensagens de texto
  • Busca de mensagens por chat
Presence

PresenceService

Gerencia status online/offline do usuário.

  • Usuário online
  • Usuário offline
  • Última vez visto (UTC)
Stories

StoryService

Gerencia stories temporários.

  • Duração fixa: 24 horas
  • Criação de story
  • Listagem apenas de stories válidos
  • Remoção automática de expirados
  • Likes em stories
Planos

PlanService

Gerencia planos, boosts e cupons.

  • Planos: Free, Plus, Premium
  • Controle de expiração
  • Boosts disponíveis
  • Duração do boost: 3 horas
  • Likes diários no plano grátis
  • Resgate de cupons
Billing

GooglePlayBillingService

Integração com Google Play Billing.

  • Compra de planos
  • Validação de assinaturas
  • Atualização de estado de compra
Admin

AdminAccessService

Controle simples de acesso administrativo.

  • Validação de UID administrador
  • Acesso a recursos restritos
Moderação

ReportService

Envio de denúncias para moderação.

  • Denúncia de usuários
  • Denúncia de mensagens ou conteúdos
  • Persistência em /reports
Suporte

EmailService

Envio de e-mails transacionais.

  • Confirmações
  • Contato com suporte
Notificações

FcmTokenService

Gerencia tokens de notificação push.

  • Registro de token
  • Atualização
  • Associação ao usuário
Push

PushNotificationBootstrapper

Inicialização e preparação do sistema de notificações.

  • Setup inicial do FCM
  • Configuração global
Localização

LocationService

Gerencia dados de localização do usuário.

  • Latitude e longitude
  • Atualização no banco
